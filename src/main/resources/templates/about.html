关于本站

这是我的个人学习网站

这里用来记录我的编程学习过程、项目练习、生活想法和成长经历。

建站目的

搭建这个网站，是为了把自己学习 Java、Spring Boot、HTML、CSS 和数据库的过程记录下来。 一方面方便以后复习，另一方面也可以展示自己的学习成果和项目经历。

网站内容

  • 学习笔记：记录 Java、Web 开发、数据库等知识点。
  • 项目记录：保存自己做过的练习项目和开发思路。
  • 个人介绍：展示我的学习方向、技能和联系方式。
  • 生活记录：记录一些日常想法和学习感受。

使用技术

本站目前使用 Spring Boot 作为后端框架，通过 Controller 返回页面， 页面部分使用 HTML 和 CSS 编写，静态资源放在 static 目录，模板页面放在 templates 目录。

后续计划

  • 增加文章详情页面。
  • 增加文章分类和标签功能。
  • 增加留言功能。
  • 连接数据库，实现文章的增删改查。
  • 将网站部署到服务器，让别人也可以访问。
