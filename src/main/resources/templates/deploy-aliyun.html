Spring Boot 项目部署到阿里云服务器

记录时间：2026-04-02 ｜ 分类：Java 部署实战

这篇笔记记录一次从本地 Spring Boot 项目打包，到上传阿里云服务器并启动运行的完整过程。 主要目的是熟悉项目部署流程，理解本地开发和服务器运行之间的区别。

一、准备阿里云服务器

可以先进入阿里云免费试用页面，选择一台 ECS 云服务器进行练习。 

https://free.aliyun.com/

拿到服务器后，需要记住几个关键信息：

  • 服务器公网 IP
  • 登录用户名，一般是 root
  • 密钥文件，例如 ecs.pem
  • 服务器系统类型，例如 Ubuntu

二、连接远程服务器

在本地电脑打开命令行，使用 ssh 连接服务器。 

ssh -i ecs.pem root@你的公网IP

如果连接成功，说明已经进入远程服务器环境，后面的命令都在服务器上执行。

三、安装 Java 环境

Spring Boot 项目需要 Java 环境才能运行。Java 只需要安装一次，不用每次部署都重新安装。 

apt update
apt install openjdk-21-jdk
java -version

执行 java -version 后，如果能看到 Java 版本信息，说明安装成功。

四、本地打包 Spring Boot 项目

在本地项目目录执行 Maven 打包命令，生成可以运行的 jar 文件。 

mvn clean package

如果使用项目自带的 Maven Wrapper，也可以执行： 

./mvnw clean package

Windows 下可以执行： 

mvnw.cmd clean package

打包成功后，jar 文件一般会出现在 target 目录下，例如： 

target/demo-0.0.1-SNAPSHOT.jar

五、上传 jar 文件到服务器

在本地电脑执行 scp 命令，把 jar 文件上传到服务器的 /root 目录。 

scp -i ecs.pem demo-0.0.1-SNAPSHOT.jar root@你的公网IP:/root

如果 jar 文件在 target 目录下，可以这样写： 

scp -i ecs.pem target/demo-0.0.1-SNAPSHOT.jar root@你的公网IP:/root

六、启动 Spring Boot 项目

进入服务器后，使用 nohup 后台启动 Java 程序。 

nohup java -jar demo-0.0.1-SNAPSHOT.jar > /dev/null 2>&1 &

这样即使退出 ssh 连接，程序也会继续在服务器后台运行。

七、查看 Java 进程

可以使用 jps 查看当前服务器上正在运行的 Java 程序。 

jps

如果能看到类似 demo-0.0.1-SNAPSHOT.jar 的进程，说明项目已经启动。

八、停止项目

如果需要停止项目，先通过 jps 找到进程 ID，然后执行 kill 命令。 

kill -9 替换实际进程ID

例如进程 ID 是 12345，就执行： 

kill -9 12345

九、退出服务器

操作完成后，可以主动退出 ssh 连接。 

exit

十、注意事项

  • 阿里云安全组需要放行项目端口，例如 Spring Boot 默认的 8080 端口。
  • 服务器防火墙如果开启，也需要允许 8080 端口访问。
  • jar 文件名要和启动命令中的文件名保持一致。
  • 如果修改了代码，需要重新打包、重新上传、重新启动。
  • 如果想用域名访问，可以后续配置域名解析和 Nginx 反向代理。

总结

这次部署让我熟悉了 Spring Boot 项目从本地开发到服务器运行的完整流程： 本地打包 jar、上传服务器、安装 Java 环境、后台启动程序、查看进程和停止服务。 通过这次实践，我对项目上线流程有了更清晰的理解，也提升了自己独立部署项目的动手能力。
